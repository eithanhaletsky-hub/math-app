# עולמות המתמטיקה

אתר לימוד מתמטיקה אינטראקטיבי לכיתות א'–ו', בעברית. אתר סטטי, בלי שרת, בלי פרסומות ובלי מעקב.

## הרצה במחשב

פעם ראשונה בלבד (מתקין את הספריות):

```bash
npm install
```

הפעלת האתר:

```bash
npm run dev
```

ואז לפתוח בדפדפן את הכתובת שמופיעה בחלון (בדרך כלל http://localhost:5173). עוצרים עם Ctrl+C.

בדיקה מהטלפון באותה רשת Wi-Fi: `npm run dev -- --host` ולפתוח בטלפון את הכתובת `Network` שמופיעה.

## פקודות נוספות

| פקודה | מה היא עושה |
|---|---|
| `npm test` | בודק שכל מחוללי התרגילים מייצרים שאלות תקינות |
| `npm run build` | בונה את האתר לתיקייה `dist` |

## מבנה

- `src/content/` — כל התוכן: עולמות, נושאים, שלבים ומחוללי תרגילים. כאן מוסיפים נושאים.
- `src/engine/` — כוכבים, פתיחת שלבים, בניית סבב שאלות.
- `src/storage/` — שמירת התקדמות ב-localStorage (עובד גם כשהשמירה חסומה).
- `src/components/` — הדמות (פיפי), רכיבי ההמחשה וסוגי התרגילים.
- `src/screens/` — המסכים: מפה, מסלול עולם, שלב.

### הוספת שלב חדש

ב-`src/content/grades/gradeX/` מוסיפים אובייקט `Level` עם `intro` (הסבר) ו-`generate()` שמחזירה שאלה אקראית, ומכניסים אותו לרשימת `levels` של הנושא. `npm test` יבדוק אותו אוטומטית.

`#/dev` — דף נסתר שמציג את כל סוגי התרגילים, לבדיקה.
